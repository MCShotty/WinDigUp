Model acceleration

Text requests are batched automatically. Available GPU memory can reduce the effective limit. Activity shows worker states and any capacity restriction.

Use an exported EmbeddingGemma 2 model bundle. Intel's NPU driver is required. NPU vectors use a separate index.

Text, image and audio model inference stays on the selected accelerator, including pooling and normalization. Unsupported operations or missing hardware stop inference. CPU fallback is disabled. File reading, decoding, tokenization and the app still use the CPU.

DigUp reads pictures, PDFs, documents (txt, md, rtf, docx, odt, html), audio and video. Keys, certificates and password files are never read, nor are hidden folders.

DigUp can find code by what it does. Type “code:” in the search panel and say what the code does, or pick Code in the window. Results open in your editor at the line.

Code folders

Open code in

DigUp reads what git keeps in these folders: source, configuration, a repository's docs and notebooks. It leaves out what git ignores, dependencies and build output, data files, keys and password files. Code gets an index of its own and shows up only when you search for code.

Enhance app descriptions online

Optional. Reads installed product IDs and versions through WinGet, then requests matching manifests from Microsoft's community catalog on GitHub. If allowed, it may fetch the publisher page listed there. Those services see the requested product and your IP address. Search queries, documents and local file paths are never sent.

Only exact product and publisher matches are used. Saved descriptions work offline. Your own purpose descriptions always take priority.

Drives

Choose Files to index supported content across a drive using your folder exclusions. Choose Applications to discover programs. You can select either or both.

Discover unregistered desktop apps on selected drives. Windows shortcuts remain the preferred launch targets. Installers, internal helpers and uncertain executables stay in review.

Optional, administrator permission required. The read-only component reads NTFS records and checks your access before returning executable paths. Other filesystems and unavailable components use slower directory discovery. The shared component remains installed when a user removes DigUp.

Privacy

DigUp reads the folders you choose and keeps what it learns in its index, on this computer. Model downloads and update checks send nothing about your files. Optional online app descriptions request installed product metadata from the sources explained in Apps; this is off by default.
