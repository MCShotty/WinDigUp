Set up DigUp

Find files by what you remember

Search the folders you choose with a filename or a description.

  • Screenshots and photos “a screenshot of an error message”
  • PDFs and documents “a receipt from the hardware store”
  • Audio and video “the part with the drums”

DigUp downloads its 865 MB model once. Your files stay on this computer, and you can search offline.

Choose folders to search

Expand a folder to leave out subfolders. DigUp watches your selected folders for changes after the first scan.

DigUp only reads files: it never changes, moves or uploads them.

Choose code folders

Choose repositories to search separately with code:. You can add them later in Settings.

DigUp reads files tracked by Git. It skips dependencies and build output. After the first scan, it reads changes as they happen.
